# Runbook: 출력제어(Curtailment) 지시 대응 절차

- 단계: 생산
- 적용 설비: pv-01, pv-02
- 적용: 계통 운영자로부터 재생에너지 출력 제한 또는 역송 제한 지시를 받았을 때
- 증상 예시: 계통 운영자의 출력 제한 지시, 역송 제한 요구, 발전을 줄여야 함

> 상황 절은 위에서부터 키워드를 확인합니다. 위험한 상황일수록 위에 두세요.

## 기본 절차
1. 지시 내용(제한 시간대, 제한 값)과 현재 태양광 출력, 연계점 역송량을 확인한다.
2. 남는 전력을 ESS 충전으로 흡수할 수 있는지 ESS 충전율 여유(충전 상한까지 남은 양)를 확인한다.
3. 흡수 가능한 만큼 ESS 충전 계획을 세우고, 부족분은 인버터 출력 제한값으로 설정한다(운영자 승인 필요).
4. 제한 시간대 동안 역송이 제한값을 넘지 않는지 15분 단위로 확인한다.
5. 종료 후 제한된 발전량과 ESS 흡수량을 기록한다.

## 상황 1: ESS가 가득 차서 남는 전력을 흡수할 수 없음
- 키워드: ESS가 가득, 만충, 흡수 못, 흡수할 수 없
- 증상 예시: ESS가 꽉 차 있음, ESS로 받을 수 없음, 충전 여유가 없음
- 판단 근거: ESS 충전율이 충전 상한에 도달
- 대응: 아래 절차(기본 절차 대신)
1. 지시된 제한 시간대와 제한 값을 확인한다.
2. ESS 흡수 없이 인버터 출력 제한값을 바로 설정한다(운영자 승인 필요).
3. EV 충전 등 앞당길 수 있는 부하가 있으면 제한 시간대로 옮긴다.
4. 제한 시간대 동안 역송이 제한값을 넘지 않는지 15분 단위로 확인한다.

## 상황 2: 일반적인 출력제어 지시 수신
- 증상 예시: 출력 제한 지시가 들어옴, 역송 제한 요구, 발전을 줄이라는 연락
- 판단 근거: 계통 운영자의 출력제어 지시
- 대응: 기본 절차와 동일

## 상황 3: 인버터가 제한값을 따르지 않음
- 키워드: 제한이 안 먹, 제한값을 안 따, 미적용, 제한이 적용 안
- 증상 예시: 출력 제한을 걸었는데 발전량이 그대로임, 역송이 계속 제한값을 넘음
- 판단 근거: 제한 설정 후에도 출력이 제한값보다 큼
- 대응: 아래 절차(기본 절차 대신)
1. 인버터와 EMS 사이 통신 상태와 제한 명령 수신 여부를 확인한다.
2. 인버터 화면에서 출력 제한을 수동으로 설정한다(운영자 승인 필요).
3. 그래도 넘으면 해당 인버터를 계통에서 분리한다(운영자 승인 필요).
4. 계통 운영자에게 미이행 사유와 조치 시각을 보고한다.

## 상황 4: 출력제어가 해제됨 (정상 운전 복귀)
- 키워드: 해제, 출력제어가 끝, 제한이 끝
- 증상 예시: 출력제어 해제 통보, 제한 시간이 끝남, 다시 발전해도 됨
- 판단 근거: 계통 운영자의 해제 통보 또는 제한 시간대 종료
- 대응: 아래 절차(기본 절차 대신)
1. 인버터 출력 제한값을 해제한다(운영자 승인 필요).
2. ESS 충전 계획을 평상시 스케줄로 되돌린다(운영자 승인 필요).
3. 제한된 발전량과 ESS 흡수량을 기록한다.
