# Runbook: 수요반응(DR) 감축 요청 대응 절차

- 단계: 공급
- 적용 설비: pcc-01, ess-01, ess-02, evc-01, load-01
- 적용: 수요반응(DR) 감축 요청이 발령되어 정해진 시간에 사용 전력을 줄여야 할 때
- 증상 예시: 수요반응 감축 요청 발령, 정해진 시간에 사용 전력을 줄여야 함, DR 참여

> 상황 절은 위에서부터 키워드를 확인합니다. 위험한 상황일수록 위에 두세요.

## 기본 절차
1. 요청 내용(감축 시간대, 감축 목표량)과 현재 연계점 수전 전력을 확인한다.
2. 감축 수단별 가능량을 정리한다: ESS 방전 여유, EV 충전 출력 조절, 비필수 부하 차단.
3. 감축 목표를 채우는 조합으로 감축 계획을 세운다(운영자 승인 필요).
4. 감축 시간 동안 15분 단위로 실제 감축량을 확인하고 부족하면 추가 수단을 투입한다.
5. 종료 후 목표 대비 실적을 기록한다(정산 근거).

## 상황 1: 이미 감축 시간이 시작됨 (긴급 대응)
- 키워드: 지금 바로, 이미 시작, 긴급, 당장
- 증상 예시: 감축 시간이 이미 시작됐음, 지금 당장 줄여야 함, 긴급 감축 요청
- 판단 근거: 현재 시각이 감축 시간대 안에 있음
- 대응: 아래 절차(기본 절차 대신)
1. 즉시 쓸 수 있는 수단부터 투입한다: 비필수 부하 차단(운영자 승인 필요).
2. ESS 방전 계획을 바로 실행한다(운영자 승인 필요).
3. EV 충전 출력을 낮춘다(운영자 승인 필요).
4. 5분 뒤 연계점 수전 전력으로 감축 효과를 확인하고, 부족하면 추가 수단을 투입한다.

## 상황 2: 감축 가능량이 목표보다 모자람
- 키워드: 감축량이 모자, 목표를 못, 감축이 부족
- 증상 예시: 줄일 수 있는 양이 목표보다 적음, 목표 감축량을 못 채울 것 같음
- 판단 근거: ESS 방전 여유 + EV 조절 + 비필수 부하 합계가 목표보다 작음
- 대응: 기본 절차 + 아래 추가 조치
1. 운영 일정상 미룰 수 있는 부하(공조 설정 온도, 조명 일부)를 추가 감축 수단으로 검토한다.
2. 그래도 모자라면 수요관리사업자에게 미달 예상량을 미리 알린다.

## 상황 3: 일반적인 감축 요청
- 증상 예시: DR 감축 요청이 왔음, 정해진 시간에 사용량을 줄여야 함
- 판단 근거: 수요관리사업자의 감축 요청 발령
- 대응: 기본 절차와 동일

## 상황 4: 감축 시간 중 ESS를 쓸 수 없음
- 키워드: ESS 고장, ESS를 못 써, ESS가 멈춰
- 증상 예시: ESS가 고장 나서 방전을 못 함, ESS 잔량이 없음
- 판단 근거: ESS 상태가 정지·경보이거나 방전 하한 근접
- 대응: 기본 절차 + 아래 추가 조치
1. ESS를 감축 수단에서 빼고, EV 충전 조절과 비필수 부하 차단으로 감축 계획을 다시 세운다(운영자 승인 필요).
