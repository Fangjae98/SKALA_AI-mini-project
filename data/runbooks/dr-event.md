# Runbook: 수요반응(DR) 감축 요청 대응 절차

- 단계: 공급
- 적용: 수요반응(DR) 감축 요청이 발령되어 정해진 시간에 사용 전력을 줄여야 할 때
- 증상 예시: 수요반응 감축 요청 발령, 정해진 시간에 사용 전력을 줄여야 함, DR 참여

1. 요청 내용(감축 시간대, 감축 목표량)과 현재 연계점 수전 전력을 확인한다.
2. 감축 수단별 가능량을 정리한다: ESS 방전 여유, EV 충전 출력 조절, 비필수 부하 차단.
3. 감축 목표를 채우는 조합으로 감축 계획을 세운다(운영자 승인 필요).
4. 감축 시간 동안 15분 단위로 실제 감축량을 확인하고 부족하면 추가 수단을 투입한다.
5. 종료 후 목표 대비 실적을 기록한다(정산 근거).
